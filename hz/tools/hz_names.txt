; Herzog Zwei (USA, Europe) -- label names for hzdis.py
;
; hzdis.py reads this file and uses the names in hz.lst and asm/hz.asm.
; Every name here was given after reading its routine in full; a note that
; starts with "?" is a best reading that still needs checking.
;
;   $ADDR  Name            ; note          ROM label (code or data)
;   $ADDR  v_name          ; note          RAM variable ($E00000 and up)
;   +$OFF  prefix_name     ; note          structure field (equate only)
;   $ADDR  .name           ; note          local label (branch target)
;
; ROM names replace sub_/loc_/tbl_/dat_ labels; a name at an address that
; has no label yet adds one (data tables). RAM names become equates at the
; top of hz.asm, written as $FFFFxxxx so (name).w assembles as today; abs.l
; operands use (name&$FFFFFF).l so their bytes stay $00FFxxxx.
; Symbols must be unique ignoring case (AS).
;
; A .name belongs to the global label before it in the source (AS composes
; it as Parent.name), so .loop can recur in every routine. Only the routine
; it belongs to may use it: hzdis.py stops if anything else does, or if an
; unnamed loc_ label between splits the routine. Name a routine's branch
; targets together, once it has been read in full.
